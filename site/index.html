I build tools for coding agents, Pokémon battle bots, and the odd toy. GitHub

Tools

  • Keyrelay — hands an API key to the command your coding agent runs, without the key going through chat. site · repo
  • tattle — a local proxy that shows what your coding agent sends to the internet and flags secrets in it. site · repo
  • agent-tracks — reads your nginx logs and reports which AI crawlers and agents visited your site. repo
  • pagewright — a small self-hosted render API: send a URL, get the rendered page back as JSON, Markdown or HTML. repo
  • logo-kit — makes a logo and a full favicon set from a name, a colour and an icon. site · repo
  • agent-skills-pack — three Claude Code skills for stepping back, getting a second opinion, and seeing options. repo
  • cole-skills — a Claude Code plugin marketplace with a security-audit skill. repo
  • android-tv-debloat — finds and reversibly turns off ads and bloat on an Android TV over ADB. repo
  • tplink-app — a terminal app that audits a TP-Link Archer router for security issues. repo
  • plane-radio — an RTL-SDR web app: planes on a map and the airband in your ears at once. repo

Pokémon VGC

  • Bring Four — enter both teams at team preview and it guesses the opponent's four and lead. site
  • vgc-engine — Pokémon battle rules rebuilt in Rust, checked against Showdown. site · repo
  • localdex — offline Pokémon reference data: species, moves, items, type chart, stat calculator. npm · PyPI · repo
  • localsets — offline Showdown battle sets, from Random Battles and Smogon. npm · PyPI · repo
  • baton_pass — a terminal Showdown client that plays the battles for you. repo
  • voltorb — a reinforcement-learning agent that plays Pokémon Pinball to fill the Pokédex. repo
